# 题型：政治选择题

- 先问题干关键词和选项的主体/范围是否一致。
- 再问其他选项为什么错：绝对化、偷换概念、因果倒置、主体错位。
- 不直接报答案。
- 一次只辨析一个选项。

## 绝对化/范围错位的反例

看到这些词先停一下：

- “只要…就…”：是充分条件还是必要条件？题干给了这个条件吗？
- “消除/杜绝/避免/根本解决”：现实表述会这么绝对吗？
- “根本原因/主要原因/直接原因”：题干问的是哪一层？
- “公民/政府/党/人大”：这个选项的主语是谁？题干问的是谁？
- “主要矛盾/基本矛盾”：这两个词能互换吗？

追问例句：

- 这个“只要”成立吗？举一个反例。
- 这个选项是“根本”还是“重要”？题干问的是哪个？
- 这句话本身对，但它回答题干了吗？
- 先把主语圈出来：谁在做这件事？

## 选项本身正确、但答非所问

- 题干问“原因”，选项说的是“表现”——对，但不是答案。
- 题干问“根本”，选项说的是“直接”——对，但层次不对。
- 题干问“体现”，选项说的是“措施”——对，但方向不对。

追问例句：

- 这句话本身没错，但它回答题干问的“原因/表现/措施”了吗？
- 题干问的是哪一类？先圈出题干动词。
- 这个选项正确，但它是“根本”还是“直接”？题干要哪个？
- 先别选“对的”，选“回答题干的”。

## 因果倒置

先看方向：谁导致谁。

- 材料说“A 导致 B”，选项说“B 导致 A”——方向反了。
- 材料说“A 是 B 的原因”，选项说“A 是 B 的结果”——关系反了。
- 材料说“因为 A，所以 B”，选项说“因为 B，所以 A”。

追问例句：

- 材料里谁在前、谁在后？先别管选项。
- 这个选项把“原因”和“结果”对调了吗？
- 是 A 导致 B，还是 B 导致 A？用一句话说方向。
- 这个“因此”在原文里有吗，还是选项自己加的？

## 选项与题干主体不一致

先圈题干主语，再圈选项主语。

常见主体：

- 党 / 政府 / 人大 / 政协 / 公民 / 企业 / 个人；
- 题干问“政府”，选项说“党”——主体换了；
- 题干问“公民”，选项说“国家”——范围换了。

追问例句：

- 题干的主语是谁？选项的主语是谁？两个一致吗？
- 这个选项说的是“政府”，题干问的是“党”吗？
- 主体换了，后面说得再对也不选。
- 先把两个主语圈出来，再判断。

## 选项因果链太长

- 选项把 A→B→C→D 串成一条链，但题干只问 A 和 D。
- 链中间有一环材料没提：整条链不成立。
- 多步因果比单步更容易“看起来对”，要逐步核。

追问例句：

- 这条因果链有几步？每一步材料都提了吗？
- 中间这一步，材料里哪句支持？没有就是断的。
- 能不能直接从 A 到 D？中间步骤是必要的吗？
- 选项把“可能”说成“必然”了吗？
