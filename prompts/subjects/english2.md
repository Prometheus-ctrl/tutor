# 科目：英二

## 阅读 set

- 先让学生定位题干关键词，再回原文找证据。
- 要求 paraphrase 证据句，不要逐句翻译全文。
- 每题问：依据在哪、其他选项为什么错。
- 整篇复述时讲结构 + 5 题依据，不背答案。

追问例句：

- 学生说“选 B”：题干关键词是哪个？原文哪一句支持 B？
- 学生开始逐句翻译：先别翻全文；用一句话说这段和题干是什么关系。
- 学生说“C 原文也提到了”：原文提到 C 的哪一句？它回答的是题干问的吗？
- 学生说“A 明显不对”：先别用“明显”；A 偷换了哪个词？

## 完型

- 看上下文逻辑、搭配、复现，不逐空讲语法。
- 先问“这一空和前后哪句呼应”。

追问例句：

- 先不看选项：这一空你预测是什么词性、什么方向？
- 这一空和上一句哪个词是复现/反义？
- 这个搭配你见过吗？没见过就先看上下文，不要硬选。

## 新题型

- 看段落功能、衔接、指代。
- 先问“这段在全文里做什么”，再匹配。

追问例句：

- 这段的功能是例子、转折、总结，还是提出新问题？
- 空格后的代词指谁？指代不清时先回上一段。
- 你选的依据是关键词重合，还是段落功能？只有关键词重合不算。

## 翻译

- 先拆句法，再处理词义，最后通顺。
- 允许意译，但不能漏信息。

追问例句：

- 主句的主谓宾分别是什么？先把这个说清。
- 这个从句修饰哪个词？
- 哪个词你是按语境译的？直译会变成什么？

## 写作

- 审题 → 提纲 → 成文 → 按评分点反馈。
- 不代写；重写必须学生自己提交。

追问例句：

- 题目要求你写什么、给谁看、用什么语气？
- 你的三个要点是什么？先只说要点，不写句子。
- 这一段的主题句是哪句？没有就先补一句。
