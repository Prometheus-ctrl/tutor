# 英语二写作评分标准

来源：用户纸质资料「一般评分标准」，2026-10-27 拍照录入。
用途：给 AI 批改提供档位锚点，不把分数当精确测量。

## 英语二档位

| 档位 | Part A | Part B |
| --- | --- | --- |
| 第五档 | 9～10 | 13～15 |
| 第四档 | 7～8 | 10～12 |
| 第三档 | 5～6 | 7～9 |
| 第二档 | 3～4 | 4～6 |
| 第一档 | 1～2 | 1～3 |
| 零档 | 0 | 0 |

## 各档描述

### 第五档

很好地完成任务：

- 包含并有效阐述所有内容要点；
- 语法结构和词汇丰富；
- 语法结构和词汇准确，错误极少；
- 有效使用多种衔接手段，内容连贯、流畅，层次清晰；
- 文体格式和语体恰当贴切；
- 对目标读者完全产生了预期效果。

### 第四档

较好地完成任务：

- 包含所有内容要点，少数要点未能有效阐述；
- 语法结构和词汇较丰富；
- 语言基本准确，只有在尝试复杂结构或较高级词汇时有个别错误；
- 比较有效地使用了一些衔接手段，内容较连贯，层次较清晰；
- 文体格式和语体较恰当；
- 对目标读者产生了预期效果。

### 第三档

基本完成任务：

- 虽漏掉一些内容，但包含多数内容要点；
- 语法结构和词汇基本满足任务需求；
- 存在一些语法或词汇错误，但基本不影响理解；
- 使用简单的衔接手段，内容基本连贯，层次基本清晰；
- 文体格式和语体基本合理；
- 对目标读者基本产生了预期效果。

### 第二档

未能按要求完成任务：

- 漏掉或未能有效阐述一些内容要点，写了一些无关内容；
- 语法结构单调，词汇有限；
- 存在较多语法或词汇错误，影响理解；
- 未采用必要的衔接手段，内容缺乏连贯性；
- 文体格式和语体不恰当；
- 未能清楚地把信息传达给读者。

### 第一档

未完成任务：

- 明显遗漏主要内容，写了许多不相关内容；
- 语法结构很单调，词汇很有限；
- 语言错误很多，内容很难理解；
- 未使用任何衔接手段，内容不连贯，缺少组织、分段；
- 无文体格式和语体概念；
- 未能把信息传达给读者。

### 零档

- 所传达的信息或所用语言太少，无法评价；
- 内容与要求无关或无法辨认。

## 给 AI 的使用规则

1. 分数只作参考，不追求精确；同一篇不同老师本来就会有差异。
2. 先判任务完成，再看语言；不要用“高级词汇”掩盖内容缺失。
3. 硬伤优先级：
   - 图表数据看错 / 题目要求没覆盖 → 任务完成受损；
   - 段落逻辑断 / 句子读不懂 / 明显语法错误影响意思 → 语言与连贯受损。
4. 没有以上硬伤时，不因为“还能更漂亮”要求重写。
5. 第五档也不等于完美；允许存在个人表达差异。
