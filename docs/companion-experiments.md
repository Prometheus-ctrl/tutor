# 学伴实验板

## 方向

```text
学生愿意一直讲
学伴不抢话
开口时能接住
只在需要时出手
一次只做一件事
```

方向稳定；具体做法都可以被真实对话和 A/B 推翻。

## 不做什么

- 不因为一次不舒服就加全局规则；
- 不同时改模型和策略；
- 不用“用户喜欢”代替学习效果；
- 不把 A/B 当成打分或考试；
- 不做 A/B 分支对话：不选一条继续、不现场分叉；
- 单次投票不触发任何行为调整，只进实验记录。

## 投票原则

- 投票只累积证据，不立刻改学伴；
- 一次错选只污染一票，不污染对话；
- 每个方向至少 10 票再判断；
- “都不喜欢”占多数时，两个候选都淘汰；
- “差不多”占多数时，暂停这个方向。

## 实验队列

按优先级：

1. 介入时机：什么时候该沉默，什么时候该开口；
2. 回复长度：一句话够不够；
3. 追问数量：零问、一问、两问；
4. 模型：DeepSeek vs Qwen；
5. 上下文：历史长度 / 是否带学生状态；
6. 提示强度：最小提示 vs 多解释一步。

前三个影响最大，先做。

## 单个实验格式

```text
假设：
变量：
A：
B：
其他不变：
指标：
样本：
决策规则：
结论：
```

规则：

- 同一道题、同一段历史、同一个学生发言；
- 只差一个变量；
- A/B 左右随机；
- 不透露哪个是新版；
- 至少 10 票再判断；
- 连续两次“差不多”就暂停这个方向。

## 第一轮

### 实验 1：介入时机

```text
假设：学伴介入太早
变量：何时开口
A：当前，学生一停就回应
B：多等一拍，学生明确卡住才回应
指标：偏好胜率 + 学生继续讲的比例 + 连续追问次数
样本：10 票
决策：B 胜率 ≥ 60%，且不增加卡住时长 → 采用 B
```

### 实验 2：回复长度

```text
假设：一句话比一段解释更舒服
变量：单轮回复长度
A：当前
B：更短，只保留一个动作
指标：偏好胜率 + 是否继续讲
样本：10 票
决策：B 胜率 ≥ 60% → 采用 B
```

## A/B 展示

自然停顿点出现，不弹窗：

```text
刚才这个场景，你更喜欢哪种回应？
A：……
B：……
[更喜欢 A] [更喜欢 B] [都不喜欢] [差不多]
```

频率：

```text
每 4～6 个学生回合最多 1 次
每个复述批次最多 3 次
两次之间至少 2 分钟
你正在讲 / 录音 / 情绪不好时不出现
```

## 判断“教得好”的保留指标

A/B 只作为体验信号。  
每轮实验同时记录：

- 学生说话占比；
- 学伴连续追问次数；
- 重复问同一点次数；
- 学伴开口后学生是否继续讲；
- 一次复述能否完成。
